# 2026-10-18

## 昨日联播（新闻联播每日要点小程序）

用户需求：小程序每天推送前一天《新闻联播》主要内容，要点清单 + 一句话总结，历史可回看。

### 完成内容

- `xwlb-miniprogram/`：原生小程序，4 个页面（首页 / 往期 / 详情 / 我的），3 个 tab
- `push-server/`：Node 推送服务，每日定时抓取 + 微信订阅消息发送 + 订阅名单维护
- `tools/`：抓取、快照生成、界面预览生成、静态自检脚本
- `xwlb-preview.html`：手机框界面预览，可直接浏览器打开
- `README.md`：完整说明

### 关键技术事实

- **数据源**：央视网栏目接口 `api.cntv.cn/NewVideo/getVideoListByColumn?id=TOPC1451528971114112`。
  返回的 `brief` 字段本身就是「本期节目主要内容」的条目列表，无需抓正文再摘要。
  每期有 19:00 和 21:00 两条，按日期去重。接口无官方文档，已做容错。
- **云应用**：`wbapp_XY1CZOcNI2vqOfKOErshrP`（昨日联播），appType=miniprogram。
- **数据库**：`daily_digest` 表（date PK / summary / tags / model），公开读 + 限长插入，无 UPDATE/DELETE。
- **架构决策**：小程序直连央视网拿最新内容，不依赖定时任务更新数据；云库只做 AI 摘要的跨用户共享缓存。
  原因：云服务没有定时任务能力，而内部写接口只允许登录用户写自己 owner_id 的行，公共内容无法由外部脚本写入。
- **SDK 引入方式**：`miniprogram_npm/` 内置了 `miniprogram_dist/miniprogram.js`（170KB 自包含 CJS bundle），
  所以不需要在开发者工具里点「构建 npm」。
- **订阅消息是一次性授权**，每天推需要用户反复授权或勾选「总是保持以上选择」——这是微信规则，已在 README 说明。
